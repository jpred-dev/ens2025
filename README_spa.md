ENS2025 es un simulador e intérprete de ensamblador en el estándar IEEE694, presentado como Trabajo Final de Grado para Ingeniería Informática de la UNED.

La aplicación carga ficheros de código escritos en ensamblador siguiendo el estándar mencionado y los ejecuta en un simulador de 65536 palabras de 16 bits con 16 registros.

Para más información sobre los registros, el simulador y las instrucciones soportadas, consúltese el manual de usuario en la carpeta de documentación (donde también puede consultarse la memoria completa del proyecto).

Se pueden descargar ficheros .jar listos para su uso desde la carpeta ENS2025 para Windows, Linux y MacOS.

El código está dividido en dos versiones: Standard y Failsafe. Esta última versión sustituye algunos caracteres y símbolos por caracteres ASCII para mayor compatibilidad, y puede usarse en caso de que los iconos de los botones o los símbolos usados para marcar la posición de los punteros no se muestren correctamente.
